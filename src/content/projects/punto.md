Raycast extension that switches the keyboard layout of selected text between Latin and Cyrillic scripts. For when you accidentally type in the wrong language

I rebuilt its layout switcher as a small Swift helper that changes the input source through macOS Text Input Source Services instead of simulating keyboard shortcuts
