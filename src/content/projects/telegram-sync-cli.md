A Telegram CLI made for agents. It syncs your chats into a local cache, so an agent can search them, run SQL over them and reply

I work on what agents can do with it: rich messages written in Markdown, editing and forwarding, voice notes transcribed locally with Whisper, and errors that say what to run next
