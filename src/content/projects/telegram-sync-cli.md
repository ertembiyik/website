A Telegram client made for AI agents by [Sergey Baus](https://www.sergeybaus.com). It keeps a local cache of your chats in sync, answers in JSON, and lets an agent search years of messages or query them with SQL

I'm contributing so agents can do more than read: rich messages written in Markdown, errors that tell an agent whether a retry will work and what to run next, and soon editing, forwarding and voice notes transcribed locally
